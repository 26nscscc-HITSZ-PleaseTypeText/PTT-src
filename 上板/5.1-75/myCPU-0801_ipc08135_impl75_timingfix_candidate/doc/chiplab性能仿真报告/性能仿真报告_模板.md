## 5. 怎么测（复现）

环境：`CHIPLAB_HOME`；seed **`5570815`**。记录 Verilator、编译器和 NEMU 路径。
改 RTL 后必须 `make verilator && make testbench`（不能只 `make run`）。换 case
或重建软件镜像前，使用 `make clean_soft`/`make clean_all` 清除对应
`run_prog/obj/*_obj` 后再运行 `configure.sh`，不要复用上一 case 的 ROM。

| 负载 | 配置（典型） | 成功标志 | 性能用途 |
|------|----------------|----------|----------|
| **lab19 硬门** | `./configure.sh --run func/func_lab19`（difftest 开） | `END by Syscall` / HIT GOOD | 功能正确；IPC 仅作短测参考 |
| **四探针** | `./configure.sh --run perf_front_stream,perf_branch_mix,perf_dcache_miss,perf_mshr_burst --disable-trace-comp --output-uart-info` | 各自结束语 + PERF | 固定微负载 A/B |
| **A0 / inner_product** | `./configure.sh --run fireye/A0,c_prg/inner_product --disable-trace-comp --output-uart-info` | 正常结束 + PERF | 高吞吐快扫 |
| **memcmp** | `./configure.sh --run c_prg/memcmp --output-uart-info` | difftest 无 mismatch | Cache 可见性 |
| **CoreMark** | `./configure.sh --run coremark --output-uart-info` | `Correct operation validated` | 综合性能 |
| **Linux 软门（默认性能主对比）** | `./configure.sh --run linux --disable-simu-trace --disable-trace-comp --output-uart-info` | UART `/ #`，干净停仿打 PERF | **默认** IPC/stall 与基线对比 |
| **Linux difftest** | 同上但**去掉** `--disable-trace-comp` | 无 mismatch + 到 `/ #`（或报告明确写未到） | 正确性；部分轮次可作 **primary IPC**（须标明；勿与软门混比） |
| **U-Boot → Linux** | `./configure.sh --run uboot_linux --disable-trace-comp --disable-simu-trace --output-uart-info` | U-Boot → `bootelf` → `/ #`（完整 cmdline 可选） | 启动链路；不替代板测 |

```bash
export CHIPLAB_HOME=...
cd $CHIPLAB_HOME/sims/verilator/run_prog
make clean_all
./configure.sh --run <case> ...
make soft_compile
make verilator && make testbench
make simulation_run_prog
```

摘数：日志中 `==================== myCPU PERF (sim) ====================` 至结束；完整 log 路径写入头注。

### 注意事项

- 同 seed、同停仿条件（`/ #` / Syscall）才可比 IPC  
- 软门 vs difftest **分列**；默认主性能表用软门；若 difftest-primary，头注与 §3 写明
- PERF 仅仿真；上板综合不依赖层次探针 / `final` dump  
- 合入类报告另加「探索未留树」与备份路径
- 发布报告列出三个仓库 commit、镜像 SHA-256 和脚本入口；大产物不入 Git
- 65 MHz 只接受 Vivado 2023.2 两次干净实现；报告等待用户证据时不得写 PASS

## 6. 必测性能指标清单

探针来源：仿真结束 `myCPU PERF (sim)`。报告至少覆盖下表。

### 吞吐 / 提交

| 指标 | PERF 行关键字 | 用途 |
|------|----------------|------|
| Commit IPC | `Commit IPC` | 主对比；相对基线算 Δ% |
| 双提交率 | `Commit dual-issue` / `vs all cycles` | 窗口是否吃满 |
| Dispatch dual / dual_ALU | `Dispatch dual` | 前端能否供双发 |
| Rename/dispatch stall | `turnover_refill` / `dispatch_stall` / `rob_stall` | rename 阻塞 vs ROB 满 |

### 预测 / 取指

| 指标 | PERF 行关键字 | 用途 |
|------|----------------|------|
| BPU all / cond 准确率 | `BPU all-branch` / `BPU cond-branch` | 误预测成本 |
| Branch MPKI all / cond | `Branch MPKI` | mispred×1000/retire；&lt;5 则少在预测器上加码 |
| RAS / predec 事件 | `RAS/predec` | ras_call / ras_ret / flush / predec_redirect |
| JTC hit/miss/train | `JTC:` | jirl 目标缓存效果 |
| IB empty / push_stall | `IB frontend` | 前端供指饥饿 vs IB 反压 |
| FTQ settle / pending | `FTQ settle/pending` | 冷启动 settle 与待取块 |
| Flush / redirect % | `Flush/redirect` | 冲刷与预译码重定向占比 |
| FTB P1 hit | `FTB (P1 response)` | 前端命中 |
| I$ hit / access | `ICache (cached)` | 取指瓶颈 |
| FTB/TAGE update overflow | `FTB update queue` / `TAGE update queue` | 训练丢失 |

### 访存

| 指标 | PERF 行关键字 | 用途 |
|------|----------------|------|
| D$ hit（总/ld/st） | `DCache (cached)` 及 load/store 子行 | 缓存效果 |
| D$ MSHR busy / pend / MWAIT | `D$ MSHR busy` / `pend` / `MWAIT` | miss 占用 |
| D$ MSHR occupancy | `D$ MSHR occupancy` | avg/max/cap；扩 MSHR 决策 |
| D$ AXI OS concurrent≥2 / max | `D$ AXI OS` | dual outstanding 是否真正吃满 |
| LSU store-order / DC wait | `LSU store-order` / `LSU DC wait` | STQ/序与等数据 |
| RS_MEM src / LSU / full stall | `RS_MEM *` | 访存发射堵点 |
| SB full | `SB  full cycles` | 提交后写缓冲 |

### 队列占用（avg / max / cap / ≥50% / ≥75% / full）

| 队列 | PERF 行 | 缩减建议依据 |
|------|---------|--------------|
| ROB pairs / valid | `ROB pairs` / `ROB valid` | full% / ≥50% 高则不宜砍 |
| RS ALU0/1、MEM、MDU | `RS ALU*` / `RS MEM` / `RS MDU` | 顶满则伤 IPC |
| SB、IB、FTQ、RAS、RAT | 对应行 | 同左；关注 ≥50% 与 ≥75% |
| FTB/TAGE update Q max | 上表 overflow 行 | overflow>0 考虑加深 |
