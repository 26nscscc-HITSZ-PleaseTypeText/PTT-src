# 优化-仿真表

> 日常改 RTL 的性能迭代手册：分钟级探针 + PERF 读数，Linux 只做候选合入 / 发版终检。  
> 配套：`Chiplab_for_sim仿真验证手册.md`（环境 / 编译 / difftest）
> PERF 出口：仿真结束 `final` 块打印 `==================== myCPU PERF (sim) ====================`

## 原则

1. **分钟级**：单测目标 ~1–3 min；可 `--disable-trace-comp` 关 difftest 提速。
2. **看 PERF，不看 `/ #`**：探针程序以 UART 打印结束语即可；IPC / hit / MPKI / occupancy 以 PERF 为准。
3. **比相对 Δ%，不比 Linux 绝对值**：同一 seed、同一软件、改前后对照。
4. **正确性闸每轮必跑**：`func/func_lab19`（保留 difftest）。
5. **Linux difftest → `/ #`**：仅候选合入或发版。

基线 seed：`BUS_DELAY_RANDOM_SEED=5570815`（与仿真手册一致）。

## 推荐跑法

```bash
export CHIPLAB_HOME=~/chiplab
cd $CHIPLAB_HOME/sims/verilator/run_prog
# 改过 RTL 先：
make verilator && make testbench

# 例：前端探针（关 difftest）
./configure.sh --run perf_front_stream --disable-trace-comp --output-uart-info
make soft && make run
# 日志：./log/perf_front_stream_log/ 内搜 "myCPU PERF"
```

多测一次配置：

```bash
./configure.sh --run fireye/A0,c_prg/inner_product,perf_front_stream --disable-trace-comp --output-uart-info
```

## 一部分 ↔ 一个仿真（推荐表）

| 面 | 仿真（已有 / 新建） | 大概耗时* | 主要看的 PERF | 决策怎么读 |
|----|---------------------|-----------|---------------|------------|
| **A 总 IPC 快扫** | `fireye/A0`（IPC≈0.95，高上限）+ `c_prg/inner_product` | ~1–3 min | Commit IPC、dual_rate | 回归：别比 Linux 绝对值，比相对 Δ% |
| **B 前端供指** | **新建** `perf_front_stream`：大顺序流 + 少分支 | ~1 min | ICache hit、I$ miss lat/MPKI、IB empty%、FTQ pending%、push_stall | I$ 扩：hit 明显↑且 IPC↑才留；IB empty 仍高→前端结构 |
| **C 分支** | **新建** `perf_branch_mix`：cond 密集 + 间接 call/ret + 普通 jirl | ~1–2 min | Branch MPKI、BPU accuracy、JTC hit、RAS flush、TAGE/FTB Q overflow | MPKI↓ 且 IPC↑；JTC P0 只在本测绿再碰 Linux |
| **D 双发** | `fireye/A0`（dual≈93%）对照 `coremark`（dual≈5%） | A0 快 / CM 稍慢 | Commit dual vs Dispatch dual、dual_ALU、ROB/RS full | 前端改动看 A0；后端相关/配对看二者 gap |
| **E D$ / miss 延迟** | **新建** `perf_dcache_miss`：工作集 ≫ L1（默 64KB；可扫 8/16/32/64KB）+ store 流 | ~1–2 min | D$ hit ld/st、ld miss lat avg/max、MSHR busy/occ、LSU DC wait、RS_MEM *stall、IPC | 扩 cache：hit↑ 且 IPC↑≥阈值（如 2%）才合入；只 hit↑ IPC 平→不扩 |
| **E′ CWF 专项** | 已有 `c_prg/memcmp`（可见性）+ `perf_dcache_miss`（延迟） | ~1–3 min | memcmp **必须 difftest 绿**；miss 测看 IPC / MSHR / `D$ CWF probe` | CWF 候选：memcmp 绿 + miss 测 IPC↑，再上 Linux |
| **F dual-OS** | **新建** `perf_mshr_burst`：同线多 miss / 指针追逐 | ~1 min | MSHR occupancy max、MSHR busy%、IPC | max 顶满且 IPC 受限才开 OS；开后本测+lab19 绿再 Linux |
| **G 队列瘦身** | 任一高 occupancy 负载：`perf_dcache_miss`+`fireye/A0`（或 memcmp / Linux 抽样） | — | occupancy max/≥75%/full、Q overflow；STQ/SB | max≪cap 可砍；触顶且 IPC 敏才加深 |
| **正确性闸** | `func/func_lab19`（保留 difftest） | ~几十秒 | 过/不过 | 每轮 RTL 必跑；不替代性能探针 |
| **终检** | Linux difftest → `/ #` | 很长 | Commit IPC | 仅候选合入 / 发版 |

\*耗时随机器与是否开 difftest / 波形变化；上表为关 difftest、无波形的量级。

## PERF 字段速查（与本表相关）

| 关心点 | PERF 行关键词 |
|--------|----------------|
| 总性能 | `Commit IPC`、`Commit dual-issue`、`Dispatch dual` |
| 前端 | `ICache`、`I$ miss lat`、`IB frontend`、`FTQ settle/pending` |
| 分支 | `Branch MPKI`、`BPU`、`JTC`、`RAS/predec`、`FTB/TAGE update queue` |
| D$ / CWF | `DCache load/store`、`D$ ld miss lat`、`D$ CWF probe`、`D$ MSHR` |
| L2 | `L2 (line rd)` |
| LSU / SB | `LSU DC wait`、`LSU STQ`、`SB nonempty/drain`、`Store buffer` occupancy |
| 队列 | `queue occupancy: avg / max / ... / full` |

说明：

- **`D$ CWF probe`**：与 CWF 是否使能无关；`early_opp` / `beat1_lo` 估「若开 CWF 可受益」次数。
- **I$ / D$ miss lat**：从 miss 服务开始到回数据的拍数（avg/max）；配合 hit_rate 看扩 cache / 开 CWF。
- **I$ MPKI**：`ic_miss_n * 1000 / retire`（与 Branch MPKI 同口径）。

## 建议日常循环

1. 改 RTL → `make verilator && make testbench`
2. `func/func_lab19`（difftest on）
3. 按改动面跑 A + 对应 B/C/E/F（difftest off）
4. 数字达标且 lab19 绿 → 再考虑 E′ / Linux 终检
